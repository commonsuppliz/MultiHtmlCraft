DOMContentLoaded + console.info

外部ライブラリを使用せず、純粋な HTML と JavaScript のみで記述したサンプルです。

コンソール（DevTools）の確認方法

  • Windows / Linux: F12 または Ctrl + Shift + I
  • Mac: Cmd + Option + I
実行中の JavaScript コード
document.addEventListener('DOMContentLoaded', () => {
  console.info('DOMContentLoaded イベントが発生しました！');
});
